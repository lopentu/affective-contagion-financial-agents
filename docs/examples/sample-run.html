The experiment

treated role
The one agent that reads the stimulus. Everyone else can learn of the event only through a peer message, or from the price. Confining it to one agent is what makes cross-agent coupling a transmission path rather than shared exposure to the same text.
stimulus
The news text, rendered from a canonical payload. Two arms carry identical financial content and differ only in affective wording.
arousal delta
How much more aroused the anxiety-like arm scores than the neutral arm. A run refuses to start if this is not measurable.
shock window
Rounds in which the stimulus is delivered. In the paper's runs it is delivered once.

Per agent

pos
Net trading position, from −1 (maximum short) through 0 (flat) to +1 (maximum long). Cumulative, not per round: HOLD leaves it unchanged rather than closing it.
arousal
NRC VAD arousal of the message this agent wrote, averaged over matched words. This is the study's primary outcome.
valence
Pleasantness on the same scale. Anxiety is high arousal and low valence.
coverage
Share of the message's words found in the lexicon. Low coverage means the score rests on few words and should not be trusted.

The market

imbalance
Mean signed order across all agents, so it is bounded by one however many trade. Six agents cannot push harder than one could.
filled
The part of a requested order the position limit could absorb. Only this reaches the market, so positions and price can never disagree.
price panel
Price against the dashed fundamental of 100, with the shock window shaded. Note the scale: a single agent's trade moves price about 0.17%, against 0.3% of per-round noise, so this line is mostly noise by construction.

Reading it critically

pipeline
The stages that actually executed, read from the run's own trace. Each shows the value it produced.
prompt / raw
Expand these on any turn. The exact text sent, and the exact text returned before parsing. Comparing the stimulus an agent read against the message it wrote is the fastest way to see whether affect survived.
parse failed
The output did not satisfy the decision grammar, so a HOLD at size 0 was substituted. Should be rare; if common, treat every action-level number with suspicion.
